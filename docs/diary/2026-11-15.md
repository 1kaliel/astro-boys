# Diary: 2026-11-15

## 00:44 UTC · DECISION · Guilherme Martins

Dashboard UI primitives: Base UI (@base-ui/react), styled with our CSS tokens; shadcn/ui not used

Why: shadcn's Vite setup assumes Tailwind and Tailwind classes, which would reverse the plain-CSS token decision; Base UI is unstyled, accessible, one package, and is the primitive layer shadcn itself builds on. Alternatives: shadcn + Tailwind (reverses the token layers), Radix Primitives (one package per component), React Aria Components (more verbose API). Chosen by Guilherme.

## 00:44 UTC · DECISION · Guilherme Martins

Burning calendar is our own year x month heatmap; map is MapLibre GL JS + react-map-gl + terra-draw, basemap OpenFreeMap

Why: FullCalendar is an events calendar (dayGrid, timeGrid, list, multiMonth views); none shows a month as one colored cell, which is our unit. MapLibre has native globe projection and handles about 4,000 L2 polygons as a GeoJSON layer; terra-draw gives the rectangle mode; OpenFreeMap needs no key but has no availability guarantee, so a minimal fallback style is planned. Rejected: react-globe.gl (three.js globe only, no flat projection or area selection, hides half the region); deck.gl deferred (its GlobeView is experimental; not needed for this volume; revisit for the L3 drill-down of native points). Replaces the Leaflet + leaflet-draw mention in the 22:07 UTC frontend DECISION. Chosen by Guilherme.

## 01:26 UTC · DECISION · Cleber

D4 burning calendar: render the year x month heatmap with @nivo/heatmap behind a thin adapter

Why: Cleber's choice for D4 as the initial renderer. nivo's HeatMap is a grid of colored cells (one per month), accepts a custom cell component (needed for the dashed estimated outline and the partial-month corner mark), is MIT, and supports React 19 (0.99.0). Colors come from our tokens (--viz-seq-*), animation off so CSS variable colors are not interpolated. Note: Guilherme's 00:44 UTC DECISION says the calendar is 'our own year x month heatmap' (rejecting FullCalendar). nivo is not an events calendar, so the reasoning against FullCalendar still holds, but his wording changes: needs his acknowledgement. Alternatives: hand-written SVG grid (kept as the fallback if nivo cannot carry the marks or the tokens), other chart libraries. Not on the challenge's suggested list, hence this entry.
